# GameTier

Веб-приложение для создания личных тир-листов игр.

## Возможности

- каталог игр с поиском, жанрами и пагинацией;
- отдельный раздел дополнений;
- редактор рангов, цветов и названий рядов;
- перетаскивание игр между тирами;
- готовые списки и черновики;
- статусы игр и дневник прохождений;
- ручное добавление игры со своей обложкой;
- светлая и тёмная темы;
- локальный профиль пользователя.

## Запуск

Проект не требует сборки. Откройте `index.html` в браузере или запустите папку через Live Server.

Все данные профиля и тир-листов хранятся в `localStorage` текущего браузера. Серверной авторизации пока нет.

## Импорт игр из Steam

1. Скопируйте `.env.example` в `.env`.
2. Получите ключ на https://steamcommunity.com/dev/apikey.
3. Запишите ключ только в локальный `.env`:

```env
STEAM_API_KEY=your_key_here
```

4. Запустите импорт:

```powershell
python .\import_steam_games.py --limit 100 --delay-ms 1500
```

Повторный запуск продолжает импорт с сохранённого места. `.env` и состояние импортера исключены из Git.

## Публикация

Статический сайт можно разместить на GitHub Pages. Файлы каталога и обложки, которые должны отображаться на опубликованном сайте, необходимо оставить в репозитории.
